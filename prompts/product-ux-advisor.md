# product-ux-advisor

## Activation Prompts

```
Revisá este producto y decime qué le falta desde el punto de vista de UX: [descripción o screenshot]
```

```
¿Qué componentes son críticos para este tipo de producto? [descripción]
```

```
Auditá el onboarding de mi app — acá está el flujo actual: [descripción/screenshot/rutas]
```

```
Este producto se siente incompleto pero no sé exactamente qué le falta, ¿podés diagnosticarlo?
```

```
¿Qué patrones UX debería priorizar primero para mejorar la activación de usuarios?
```

## Example Use Cases

- Diagnosticar que una plataforma AI as a Service le falta un wizard de setup de API key y un empty state útil
- Identificar que un dashboard B2B no tiene activation checklist y por eso los usuarios no llegan al "aha moment"
- Detectar que falta un comando palette en una herramienta para developers
- Priorizar qué construir primero: onboarding wizard vs empty states vs tooltips
- Revisar un flujo de signup y detectar dónde se van los usuarios
