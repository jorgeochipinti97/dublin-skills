# landing-page-architect

## Activation Prompts

```
Armame una landing page para [producto / objetivo]
```

```
Necesito una landing de captación de leads para [audiencia]
```

```
Blueprint de landing para venta directa de [oferta]
```

```
Landing page de waitlist para lanzamiento de [producto]
```

```
I need a conversion-optimized landing page for [product/offer]
```

```
Build a landing blueprint for my SaaS trial page
```

## Flow

1. The skill blocks and asks for context (goal, product, audience, awareness, mechanism, pains, proof, objections, CTA, language, tone).
2. You answer in one block.
3. The skill outputs a Markdown blueprint (strategy + copy + section hierarchy + design notes).
4. Pass the blueprint to `product-ux-advisor` for UX audit.
5. Pass the reviewed blueprint to `premium-frontend-design` for implementation.

## Example Use Cases

- SaaS free trial landing for a B2B product
- Lead gen page with a downloadable template
- Waitlist / early access for a product launch
- Webinar or event registration page
- High-ticket course or coaching sales page
- App download page with store badges
- Newsletter subscription page
- Demo booking page for B2B enterprise sales
