```

```

```

```

```

```

```
Add a step-by-step tour that shows users how to [feature]
```

```
Create an interactive onboarding experience for [product]
```

## Example Use Cases

- First-time user tour highlighting sidebar, create button, and settings
- File upload walkthrough that waits for user to complete each step
- Multi-page setup wizard tour (connect account → configure → invite team)
- Activation checklist with progress bar (like Notion's "Getting Started")
- Welcome modal with step indicators for new signups
- Feature discovery beacons for newly released features
- SaaS onboarding flow with intent-based routing
