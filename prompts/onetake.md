# onetake

## Activation Prompts

```
Haceme un video de lanzamiento de 15 segundos para mi app
```

```
Armá un demo de la feature de exportar, rehaciendo la UI desde estas capturas (sin grabar pantalla)
```

```
Este video parece un PowerPoint, decime por qué y arreglalo
```

```
Hacé la versión en inglés del video con voz en off y subtítulos
```

```
Make a 30-second launch teaser for this skill
```

## Example Use Cases

| Scenario | What the skill does |
|----------|---------------------|
| Launch clip | Concept → beat sheet → single HTML comp → draft render 1080p30 → final 4K60 with SFX |
| Feature demo | Rebuilds the real UI in HTML from screenshots; a hand drives every interaction |
| Slideshow audit | Runs the oracle (`verify_promo.py`) and flags beats that replace instead of carry |
| Localized cut | Swaps voice-over + subtitles, retimes beats to the new narration |
