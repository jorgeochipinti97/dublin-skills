# remotion-video

## Activation Prompts

```
Haceme un video promo de mi landing con el hero animado
```

```
Generame un video vertical para Instagram con las 3 features principales
```

```
Creá un intro de 5 segundos con mi logo
```

```
Quiero un video animado del componente HeroSection
```

```

```

```
Create a 15-second product demo video from my React components
```

## Example Use Cases

- Promotional videos for landing pages
- Instagram Stories/Reels from existing UI components
- TikTok vertical videos with animated features
- YouTube intro/outro animations
- Product demo videos with animated UI
- Logo reveal animations
- Feature showcase videos for social media
- Animated hero sections exported as video
