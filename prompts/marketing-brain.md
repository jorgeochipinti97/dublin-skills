# marketing-brain

## Activation Prompts

```
Armemos el contexto de producto de mi app antes de hacer el video
```

```
¿Qué principio psicológico conviene para este anuncio y por qué?
```

```
Dame 5 ganchos alternativos para este guion, para testear en Reels
```

```
¿Quién es mi público ideal y qué objeciones tiene?
```

```
Generate ad angles and headline variants for Meta from this product context
```

## Example Use Cases

| Scenario | Mode | Output |
|----------|------|--------|
| New client / product | 1 · Contexto | `.agents/product-marketing.md` (positioning, ICP, pains, objections, customer language) |
| Choosing the concept of a video | 2 · Psicología | One dominant principle + why it moves the belief shift |
| Hook testing | 3 · Creativos | 3-5 hooks/angles of the same script, matched to awareness stage |
| Iterating ads | 3 · Creativos | New variants grounded in performance data |
