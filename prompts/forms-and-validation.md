## Example Use Cases

- Signup / login / password reset forms
- Multi-step checkout / onboarding wizards
- Settings forms with dirty-state detection
- File upload (direct-to-S3 with presigned URLs)
- Dynamic field arrays (invoice lines, team members)
- Server Action integration with error mapping
- Full a11y (aria-invalid, aria-live, focus management)
