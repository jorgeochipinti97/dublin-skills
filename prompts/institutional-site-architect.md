# institutional-site-architect

## Activation Prompts

```
Armame el sitio institucional de [empresa / organización]
```

```
Necesito diseñar la web de una agencia/estudio de [servicio]
```

```
Diseñá el website corporativo para [B2B SaaS / VC / law firm / nonprofit / ...]
```

```
Design an institutional site for [organization type]
```

```
Necesito la arquitectura completa del sitio web de [organización] — sitemap, nav, copy direction
```

```
Build the brand site blueprint for my [agency / startup / firm / nonprofit]
```

## Flow

1. The skill blocks and asks for context: org type, mission, audiences, positioning, differentiators, proof available, sections needed, tone, language, constraints.
2. You answer in one block.
3. The skill outputs a Markdown blueprint: positioning, sitemap, nav architecture, per-page blueprints, brand voice guide, trust strategy, SEO + legal notes.
4. Pass to `product-ux-advisor` for UX audit (nav patterns, multi-audience flows, accessibility).
5. Pass to `premium-frontend-design` for implementation (editorial typography, motion, dark mode).
6. For a specific conversion sub-page inside the site (lead gen, webinar), pair with `landing-page-architect` for that page only.

## When to Use vs landing-page-architect

- **institutional-site-architect** → multi-page site, multi-audience, brand/authority (company sites, agencies, law firms, VC, nonprofits, personal brands)
- **landing-page-architect** → single page, single goal, direct-response conversion (waitlist, lead magnet, sales letter, demo booking)

Use both together when an institutional site needs a dedicated conversion page inside.

## Example Use Cases

- B2B SaaS marketing site (home, product, pricing, customers, company)
- Design / dev studio portfolio + services site
- Law firm with practice areas + lawyer profiles
- Venture capital firm (thesis, portfolio, partners, writing)
- Enterprise multi-audience site (customers + investors + talent)
- Nonprofit with mission + programs + donate
- Personal brand site (author, founder, speaker)
- Early-stage startup landing (manifesto + waitlist + careers)
- Professional services (consulting, accounting, financial advisory)
- E-commerce brand-forward site (not just catalog)
